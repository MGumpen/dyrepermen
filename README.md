# Dyrepermen

App for dyrehold. Under produksjon.

## Brancher

| Branch        | Formål                                            |
| ------------- | ------------------------------------------------- |
| `main`        | Produksjon. Kun stabil, utgivelsesklar kode.       |
| `dev`         | Integrasjon. Alt arbeid samles her før produksjon. |
| `feature/mvp` | Første versjon av appen (MVP).                     |

Arbeidsflyt: `feature/*` → `dev` → `main`.
